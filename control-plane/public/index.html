Deploy Log

Every push to main deploys to the test site first (automatic). Production deploys to all clients are deliberate and manual — test the test site before deploying everyone.

Database Backups

Backups run automatically daily at 3 AM. Uses pg_dump for each client's Neon database. Old backups auto-delete after 7 days. Requires pg_dump CLI on the server (available in Render paid plans).

Control Plane Users

Client Health & Operations Center

Availability is derived from the 5-minute pull plus each client's pushed heartbeat. Alerts, incidents, config drift, diagnostic reports, support access and maintenance windows are logged here and audited. Secrets are never stored or shown.
